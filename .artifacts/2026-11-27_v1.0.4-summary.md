## Implemented Behavior (v1.0.4)
1. **Linear-Time `O(N)` Markdown Scanner (`ui/src/markdown.js`):**
   - Eliminated nested-quantifier link/image regexes (`(?:[^()\s]+|\([^()\s]*\))+`) and replaced them with `replaceMarkdownLinksAndImages`, backed by a single-pass `Int32Array` bracket/parenthesis delimiter map (`buildDelimiterMaps`), `matchBracketParen`, and non-recursive `flattenLabelText`.
   - Handles linked badges `[![alt](img)](href)` including empty `]()` destinations (falling back cleanly to escaped alt text), standalone images `![alt](src)`, balanced parentheses inside URLs (such as Wikipedia links), and compound nested `[prefix ![img](src)](href)` labels without generating nested interactive `<button>` or `<a>` tags.
   - Removed superlinear/quadratic backtracking across emphasis (`replacePairedDelimiter` for `**`, `__`, `~~` and linear `[^*\n]+` for `*`), bare-URL punctuation trimming (`trimTrailingUrlPunctuation`), ATX heading suffix stripping (`stripTrailingHeadingHashes`), pre-trimmed code-fence matching, and `sanitizeMarkdownUrl` trailing-slash trimming.
2. **Inline Placeholder Token Restoration & Flattened Emphasis (`ui/src/markdown.js`):**
   - Restores inline-code `\x00P<n>\x00` tokens via `restore(...)` prior to stashing or wrapping in `flattenLabelText`, standalone images, and linked badges so zero raw NUL bytes or placeholder strings leak into rendered HTML.
   - Preserves emphasis formatting (`restore(formatEmphasis(esc(inner)))`) for flattened inner link labels inside compound links.
3. **Drawer Sequence Guard & Error Boundary (`ui/src/main.js`, `ui/src/drawer.js`):**
   - Added monotonic `drawerSeq` tracking in `openDrawer` and `closeDrawer` (`ui/src/main.js`) so stale `mp_get_plugin_detail` responses from rapid plugin clicks are discarded cleanly and `state.drawer.loading = false` is cleared before `renderDrawer()`.
   - Safely optional-chained `summary.release?.ref || "release"`, `summary.release?.sha || ""`, and `summary.release?.contentTreeSha256 || ""` in `ui/src/drawer.js`, and wrapped drawer body generation in a `try/catch` boundary rendering an explicit `.mp-alert-danger` diagnostic panel on unexpected formatting failures.
4. **Regression Tests & `v1.0.4` Release Packaging (`tests/markdown.test.mjs`, `CHANGELOG.md`, `ui/dist/marketplace.html`):**
   - Added tests covering empty-href badges, balanced Wikipedia URL parentheses, compound nested link/image flattening, inline-code token restoration and emphasis preservation inside labels, and 10KB–50KB adversarial ReDoS + 15KB badge-heavy README benchmarks.
   - Bumped version metadata to `1.0.4`, added end-user release notes in `CHANGELOG.md`, and verified `npm run build:ui` (`345.98 kB`), `node --test ./tests/*.test.mjs` (`76/76` across `21` suites), `npm pack --dry-run` (`21` files), `32/32` `node --check`, and `audit-gate.js` (`10/10` PASS).
